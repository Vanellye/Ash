# Mattignation Rollout Checklist

- [ ] Confirm source scope and declared purpose.
- [ ] Preserve source reference and SHA-256 digest.
- [ ] Validate schema before processing.
- [ ] Assign explicit evidence class to each claim.
- [ ] Keep observations separate from inferences and simulations.
- [ ] Evaluate contradiction, freshness, provenance, privacy, and downstream-use risk.
- [ ] Quarantine unresolved records from trusted publication.
- [ ] Record each transition in append-only lineage.
- [ ] Bind review to exact content and operation digests.
- [ ] Require human approval for consequential actions.
- [ ] Verify approval expiry, revocation, actor authority, and target scope.
- [ ] Store corrections as linked new records; never silently rewrite history.
- [ ] Exchange with Lumi read-only by default.
- [ ] Run synthetic tests and independent review before claiming production readiness.
